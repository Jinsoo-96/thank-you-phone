# 감사전화
아이패드 11인치 가로용 정적 HTML PWA. 운영자가 종료할 때까지 녹음합니다.

## 사용
Safari에서 배포 주소 열기 → 공유 → 홈 화면에 추가 → 앱 실행 → 마이크 허용.
USB 마이크로 짧게 시험 녹음하고 관리 → 종료하고 저장 → 재생 / 내보내기 준비 → 파일 앱에 저장.
실제 입력 마이크 및 재생 음성을 확인한 뒤 본 녹음을 시작하세요.
충전 상태와 화면 켜짐을 유지하고, 자동 잠금을 ‘안 함’으로 설정하세요.

## 보관
5초 간격으로 전달되는 녹음 데이터를 IndexedDB에 저장합니다. 전달 주기는 OS 상태에 따라 늦어질 수 있습니다.
삭제 기능, 자동 만료, 내보내기 후 원본 삭제는 없습니다. 이전 녹음은 목록에 유지됩니다.
브라우저 저장은 영구 저장 보장이 아닙니다. 저장 공간 부족, 사이트 데이터 삭제, 앱/기기 문제로 손실될 수 있습니다.
파일 앱 저장은 사용자의 공유/다운로드 조작이 필요하며, 웹앱이 임의 폴더에 자동 저장할 수 없습니다.
종료 후 파일 앱에 저장하고 크기와 재생을 확인하세요. 중요한 파일은 다른 기기나 iCloud에도 복사하세요.
갑작스러운 강제 종료 시 마지막 데이터는 손실될 수 있으며, 중단된 MP4 파일은 재생되지 않을 수 있습니다.
2시간 무중단 녹음 및 USB 입력은 실제 사용할 아이패드에서 사전 시험해야 합니다. 기기에서 검증하지 않은 상태입니다.

## 구성
index.html, style.css, app.js, manifest.webmanifest, sw.js와 앱 아이콘. 서버나 외부 전송 없이 기기에만 녹음합니다.
GitHub Pages의 main 브랜치 루트에서 배포합니다.
